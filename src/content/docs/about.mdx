## How I got here

{/* no-enhance */}
- **Principal Software Engineering Manager**, Microsoft (2022 – present). Azure Health Data Services FHIR service and, since 2026, the Dragon Copilot Context Service.
- **Senior Software Engineering Manager**, Microsoft (2021 – 2022). Grew the FHIR team and set up its engineering practices.
- **Senior Software Engineering Lead**, Microsoft (2018 – 2021). Took Azure API for FHIR from public preview to general availability.
- **Software Engineer II**, Microsoft (2015 – 2018). Rebuilt the Azure.com backend to run in every Azure region, and built the Azure Pricing Calculator.
- **Senior Consultant and Developer**, Readify (2009 – 2015). Team lead and developer on client projects for Telstra, Virgin Australia and Microsoft.
- **Analyst Programmer**, Stella Hospitality Group (2005 – 2009). Where it started: ASP.NET and C# web applications for Mantra hotels.

Master of Project Management (Leadership), University of Southern Queensland. Bachelor of Information Environments, University of Queensland.

## Why this blog?

I started **kowitz.net** as a place to:

1. **Share knowledge** - Document learnings from health data, FHIR, building complex software and services, and AI development
2. **Connect with others** - Engage with the developer community
3. **Think out loud** - Writing helps clarify thinking and solidify understanding
4. **Build in public** - Show the process, not just the results
